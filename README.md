# Мото-аукцион-бот для Telegram

Бесплатный Telegram-бот на GitHub Actions. Любой, кто на него подпишется, сам
командами настраивает себе фильтры (марка, модель, годы, максимальная цена) и
получает уведомления только про новые подходящие лоты — с прямой ссылкой на лот.

Источники:
- **bid.cars** — агрегатор Copart + IAAI (США), раздел Motorcycle. Использует
-   настоящий JSON-эндпоинт поиска сайта, проверено вживую.
-   - **japanlife-moto.ru** — брокер японских аукционов целых мотоциклов. Продаёт
    -   только японские марки: Honda, Kawasaki, Suzuki, Yamaha, BMW, Harley-Davidson.
    -     Парсинг HTML эвристический — если сайт поменяет вёрстку, может сломаться.
 
    - Бот не висит в сети постоянно (это невозможно бесплатно на GitHub Actions) —
    - вместо этого раз в 15 минут запускается, забирает накопившиеся сообщения от
    - пользователей, обрабатывает команды и проверяет аукционы. То есть команда в
    - боте отработает не мгновенно, а в течение ~15 минут.
 
    - ## Команды бота
 
    - ```
      /start либо /help          — приветствие и список команд
      /watch Марка | Модель | Год_от | Год_до | Макс_цена
                                    любое поле кроме марки можно заменить на «-»
      /mywatches                  — список своих правил с номерами
      /unwatch НОМЕР               — удалить правило
      ```

      Примеры:
      ```
      /watch Aprilia | Tuono V4 | 2015 | 2024 | 8000
      /watch Honda | - | - | - | -
      ```

      ## Настройка (10-15 минут)

      ### 1. Создайте Telegram-бота
      В Telegram откройте **@BotFather** → `/newbot` → получите токен вида
      `123456789:AA...`. Это единственный секрет, который нужен боту.

      ### 2. Создайте репозиторий на GitHub
      Создайте **приватный** репозиторий и загрузите туда все файлы отсюда.

      ### 3. Добавьте секрет
      **Settings → Secrets and variables → Actions → New repository secret**
      - имя: `TELEGRAM_BOT_TOKEN`
      - - значение: токен из шага 1
       
        - (Больше секретов не нужно — chat_id подписчиков бот узнаёт сам, когда они
        - пишут ему `/start` или `/watch`.)
       
        - ### 4. Разрешите боту коммитить
        - **Settings → Actions → General → Workflow permissions** → **"Read and write
        - permissions"** → Save. Нужно, чтобы бот мог сохранять список подписчиков и
        - уже увиденные лоты обратно в репозиторий.
       
        - ### 5. Запустите вручную и проверьте
        - **Actions → Auction watcher → Run workflow**. Напишите боту в Telegram
        - `/start`, затем `/watch Aprilia | Tuono V4 | 2015 | 2024 | 8000` (или свою
        - марку) — в течение ~15 минут (либо сразу после следующего Run workflow)
        - бот подтвердит правило и начнёт присылать подходящие лоты.
       
        - ## Частота проверки
        - `.github/workflows/watch.yml`, строка `cron: "*/15 * * * *"`. На бесплатном
        - GitHub для приватного репозитория лимит — 2000 минут Actions в месяц, так что
        - слишком часто ставить не стоит (при 15 минутах и ~1 минуте на прогон это
        - примерно 2900 минут/месяц с запасом — если лимит важен, поставьте 20-30 минут
        - или сделайте репозиторий публичным, тогда лимита минут вообще нет).
       
        - ## Ограничения и что может сломаться
        - - bid.cars — проверенный API, должен работать стабильно.
          - - japanlife-moto.ru — эвристический разбор HTML и эвристический же поиск
            -   года/цены в тексте карточки. Если фильтр по цене или году не сработал как
            -     ожидалось для лота с этого сайта — дело в этом; попросите поправить.
            - - Для марок вне Honda/Kawasaki/Suzuki/Yamaha/BMW/Harley-Davidson
              -   japanlife-moto.ru не проверяется вообще (там таких лотов не бывает) —
              -     для них работает только bid.cars.
              - - Для японских аукционов вроде Yahoo Auctions Japan (частные объявления,
                -   в т.ч. от Aprilia/Ducati и т.п.) отдельно рекомендуем **japanalerts.com** —
                -     готовый сервис с собственным Telegram-ботом, ничего программировать
                -   не нужно.
               
                -   ## Если что-то не работает
                -   - Бот не отвечает на команды → проверьте секрет `TELEGRAM_BOT_TOKEN` (шаг 3)
                    -   и что workflow реально запускается (вкладка Actions).
                    -   - Ошибка про git push в логах → проверьте шаг 4 (права на запись).
                        - - Лотов долго нет → возможно, их правда нет по вашим критериям — проверьте
                          -   сами на bid.cars/japanlife-moto.ru, что фильтр не слишком узкий.
